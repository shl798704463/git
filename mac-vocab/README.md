# 词航 Lexicon — macOS 离线英语学习 MVP

面向商务沟通、AI 数据中心（AIDC）和电力电子的轻量背词应用。48 个原创示例词条，每个方向 16 个；含中英文释义及双语例句。零第三方依赖，无网络请求、账户或构建步骤。

## 安装与启动

1. 在 GitHub 选择 **Code → Download ZIP**，解压。
2. 打开 `mac-vocab` 文件夹，双击 `index.html`，选择 Safari 打开（也可在 Safari 的“文件 → 打开文件”选择它）。请保留同目录的 `app.js`、`words.js`、`style.css`。
3. 可将文件夹拖到 Dock 右侧，方便下次打开。`Open.command` 是可选启动器；如 macOS 阻止它，直接打开 `index.html` 即可，无需更改系统安全设置。

本版本是浏览器运行的本地应用，不是 Swift 原生应用或经过公证的 `.app`。无需 Xcode、Node、Python、安装器或服务器。推荐 macOS 13+ 的 Safari 16.4+，也可使用现代 Chrome。尚未覆盖所有 macOS/Safari 版本组合。

## 学习

- 选择词库和“看英文忆中文 / 看中文忆英文”。先口头回忆或输入答案，按“显示答案”核对释义和例句。
- 按自己的回忆情况选择重学、困难、记住、轻松。此版本采用自评，不自动判定输入答案。
- 到期复习优先，其次新词；未到期词可在“全部词库”检索查看。
- 重学 10 分钟；困难至少 1 天（旧间隔 ×1.2）；记住至少 1 天（×2.5）；轻松至少 4 天（×3.5）。这是简化的间隔重复算法，不是 FSRS / SM-2。
- 进度包含今日评分次数、已学词条和最近 14 个有学习记录的日期；“熟悉”指间隔达到 21 天。

## 保存与备份

进度自动存入当前浏览器的 localStorage。保持同一浏览器、同一文件位置，避免隐私浏览。移动文件、切换浏览器、清除网站数据可能使记录无法读取。定期“导出学习备份”，升级或移动文件前尤其要先备份，再“导入备份”。导入会确认后替换记录，格式错误不会替换。没有云同步。输入的回忆草稿不会保存；评分及排程会保存。

本地文件的浏览器存储策略可能随版本变化。若无法保存，界面会显示错误且不会推进词卡。浏览器崩溃或清理数据时只能通过已导出的备份恢复。

## 维护词库

编辑 `words.js` 中的 `window.WORDS` 数组，保持词条 `id` 唯一且长期稳定。每项含 `id/category/term/zh/en/example/exampleZh`。技术内容用于语言学习，不作为工程设计规范。

## 验证

在具备 Node.js 的开发环境运行 `node test.cjs`（仅开发验证需要 Node）。包含排程、到期边界、备份校验的自动测试。界面验证记录见 `VERIFICATION.md`。
